# Pasta de assets (sprites)

Coloque aqui os arquivos de arte (PNG) que você baixar/comprar. O Vite serve
esta pasta na raiz, então um arquivo `trees.png` aqui vira acessível em
`/assets/trees.png` dentro do jogo.

## Como usar

1. Baixe/compre o pack (ex.: o pack de 100 árvores da WsT).
2. Extraia o `.zip`.
3. Copie o PNG do spritesheet para esta pasta com um nome simples, por exemplo:
   - Árvores: `trees.png`
   - Chão/terreno: `terrain.png`
   - Personagem: `character.png`
4. Me avise o nome do arquivo e, se souber, o tamanho de cada sprite
   (ex.: 64x64). Eu conecto no motor.

## Importante sobre licença

Assets **comprados** (como o pack de árvores) normalmente **não podem ser
redistribuídos**. Por isso esta pasta está no `.gitignore`: os arquivos ficam
só na sua máquina e não vão para um repositório público. Guarde o recibo da
compra e qualquer arquivo de licença que venha junto.

Os créditos de cada pack usado ficam registrados em `CREDITS.md` na raiz.
